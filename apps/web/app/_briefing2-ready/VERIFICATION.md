# 브리핑2 원본 연결 검증

원본 앱의 `/?tab=brief2`에 07을 연결했다. 기존 브리핑은 유지한다.
아래는 로컬 통합 검증이며 원격 배포 검증은 아니다.

## 통과

- 단위·서버 렌더·읽기 전용 조회·채널 이동 계약·필터 결과 0건 검사: 28개.
- 원본 core/pipeline/web 타입 검사 및 Next.js 프로덕션 빌드.
- 준비본과 원본 브리핑2의 카드 내용·순서·건수·원문 URL·사용량·추이 일치.
- 전체, 복수 플랫폼 서비스 2종, 빈 서비스 × 화면 너비 1440/1050/780/390/320px: 20개 레이아웃 확인.
- 서비스 선택/전체 복귀, 날짜 폼과 서비스 유지, 유효한 빈 날짜, 잘못된 날짜 처리.
- 자바스크립트를 끈 브라우저에서도 GET 날짜 폼이 brief2 탭과 서비스를 유지.
- 피드백 펼치기, 높이 전환 시 피드백 열림 상태 보존.
- 흰 카드·테두리·보통 굵기 본문·290/320px 높이 제한 유지.
- 작은 화면의 공통 탭 이름이 한 줄을 유지하며 가로 이동.
- 브리핑 ↔ 브리핑2 이동에서 날짜·서비스 유지, 브라우저 뒤로 가기.
- 건수·피드백 더 보기에서 전체 기간 채널별 화면으로 이동, 서비스·국가·감성 유지.
- 목록·카드·채널별·수집·설정 탭의 기존 화면 표시.
- 비브리핑 탭에서 브리핑2 진입 시 오늘 날짜를 강제로 넣지 않음.
- git diff 공백 오류 없음.
- 브라우저 실행 오류 없음. 데스크톱·모바일 스크린샷도 확인.

저장 자료는 읽기만 했으며 실제 글 내용이나 스크린샷은 이 전달 폴더에 넣지 않았다.
원본 개발 서버와 빌드는 기존 `.next` / `.next-prod` 분리 설정을 사용한다.

## 범위와 제한

- 수집·분류·AI 재생성·설정 저장은 실행하지 않았다. 검증 서버는 웹만 실행한다.
- 기존 브리핑, 채널별 디자인, 전역 CSS를 대체하지 않았다.
- 채널별 화면에 특정 작성일 필터를 추가하지 않았다. 전체 기간 이동을 링크에 명시한다.
- 미지원 서비스와 모호한 국가 범위는 일반 텍스트로 남겨 잘못된 목록으로 확대하지 않는다.
- 준비본의 원문 URL을 비교했으며 외부 원문 사이트 자체에는 접속하지 않았다.
- 원격 배포 환경은 확인하지 않았다.

별도 작업본과 07 시안은 유지했다. 이 기록은 로컬 코드·화면 검증이며 원격 배포 상태를 뜻하지 않는다.
