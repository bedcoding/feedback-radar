8편 모두 같은 6개 절로 되어 있다 — 1 현황 / 2 적법성 근거 / 3 비용 / 4 연동 방법 / 5 붙인 뒤 확인할 것 / 6 출처.

## 출처 링크를 검토할 때

문서 12편에 **외부 출처 링크가 188개**(고유 기준) 들어 있다. 각 문서 6절이 그 문서의 출처 목록이다.

**링크를 눌렀을 때 404나 401이 나오는 경우가 있는데, 대부분 정상이다.** 검토 전에 알아 둘 것:

| 응답 | 개수 | 의미 |
|---|---:|---|
| **200** | 100 | 그대로 열린다 |
| **401** | 19 | **인증이 필요한 API 엔드포인트다.** 키 없이 열면 401이 맞다 (`api.appstoreconnect.apple.com`, `api.x.com`, `dapi.kakao.com`, `naverapihub…`) |
| **400** | 16 | **파라미터 없이 GET한 API 엔드포인트.** `developers.facebook.com` 문서 페이지는 curl에 400을 주지만 **브라우저에서는 정상적으로 열린다**(봇 차단) |
| **404** | 9 | 아래 참고 |
| **403** | 1 | 한국경제 기사. 봇 차단이라 브라우저에서는 열린다. 같은 사실에 [한국일보](https://www.hankookilbo.com/news/article/A2021082313250001154) 인용을 함께 달아 두었다 |

### 🔴 404가 곧 근거인 곳이 있다

**아래 넷은 "페이지가 없다"는 사실 자체가 판정의 근거다.** 깨진 링크가 아니다.

| URL | 404가 뜻하는 것 |
|---|---|
| `theqoo.net/robots.txt` | 더쿠에 robots.txt가 **없다** → 명시된 제한도, 허가도 없다 |
| `theqoo.net/terms` | 더쿠에 이용약관 페이지가 **없다** |
| `search.dcinside.com/robots.txt` | 우리가 실제로 요청하는 호스트에 robots.txt가 **없다** |
| `cs.daum.net/terms/terms.html` | 다음 카페 전용 약관을 **찾지 못했다**(미해결 항목으로 표시해 둠) |

나머지 URL 41개는 **URL 템플릿·코드 조각**이다(`{앱ID}`, `${cafe}`, 정규식 등). 열리지 않는 것이 정상이다.

### 다시 확인하려면

```bash
grep -rhoE 'https?://[^ )\]|>`"]+' docs/ | sed 's/[.,;]$//' | sort -u | while read -r u; do printf '%s %s
' "$(curl -sL -m 20 -o /dev/null -w '%{http_code}' -A 'Mozilla/5.0' "$u" </dev/null)" "$u"; done
```

> **판례·법령 링크 9개는 전부 확인했다**(한국경제 403 제외, 사유는 위 표).
> 법무 검토에서 실제로 클릭할 링크들이라 따로 찍었다.

## 소스별 문서에 없는 것

아래 넷은 소스마다 다르지 않아 각 문서에 쓰지 않았다. 전부 [`packages/core`](../../packages/core/src)에 있다.

| 무엇 | 어디 |
|---|---|
| **RawItem 계약** (수집기가 반환하는 10개 필드) | [`types.ts`](../../packages/core/src/types.ts) `RawItem` |
| **중복 판정 키** — `UNIQUE (source, source_id)`, 충돌 시 무시 | [`store.ts`](../../packages/core/src/store.ts) `ON CONFLICT (source, source_id) DO NOTHING` |
| **도배 제거** — 본문 앞 120자가 같은 글이 3건 이상이면 1건만 남김 | [`dedupe.ts`](../../packages/core/src/dedupe.ts) `dropFlooding()` |
| **수집 상한** — 소스별 기본값·최대값·단위 | [`collect-limits.ts`](../../packages/core/src/collect-limits.ts) `COLLECT_LIMIT_FIELDS` |

각 문서의 4-4절(RawItem 매핑)은 이 계약의 어느 칸을 그 소스가 못 채우는지만 적는다.
중복 판정 키는 소스 문서에 반복해서 나오는데, 저장이 갱신이 아니라 무시라서
"이미 본 글이 수정돼도 새 본문이 영영 안 들어온다"가 여러 소스에서 같은 함정으로 걸리기 때문이다.
