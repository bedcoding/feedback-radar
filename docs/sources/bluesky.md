# 블루스카이 (Bluesky / AT Protocol)

> **한 줄 요약**: 이 저장소에서 **유일하게 운영자가 자동 수집을 명시적으로 환영하는** 소스다.
> robots.txt가 "may crawl anything"이라 적고 대량 수집이면 API를 쓰라고 안내까지 한다.
> 무료이고 승인·심사도 없다. 필요한 것은 무료 계정과 앱 비밀번호뿐이다.

- **실측일: 2026-09-06** (robots.txt·약관·API 응답 모두 이 날짜에 직접 받아 확인했다)
- 관련 코드: [bluesky.ts](../../apps/pipeline/src/collectors/bluesky.ts)

## 2. 적법성 근거

### 2-1. robots.txt 실측

- URL: <https://bsky.app/robots.txt>
- **원문 전체:**

```
# Hello Friends!
# If you are considering bulk or automated crawling, you may want to look in
# to our protocol (API), including a firehose of updates. See: https://atproto.com/

# By default, may crawl anything on this domain. HTTP 429 ("backoff") status
# codes are used for rate-limiting. Up to a handful concurrent requests should
# be ok.
User-Agent: *
Disallow: /intent/compose
Allow: /

Sitemap: https://bsky.app/sitemap/users.xml.gz
```

**막는 것은 `/intent/compose`(글쓰기 화면) 하나뿐이고 나머지는 `Allow: /`다.**

> 🔵 **이 저장소에서 조사한 30여 곳 중 유일하게 수집을 권하는 문서다.**
> 다른 사이트들이 `ClaudeBot`·`GPTBot` 같은 이름을 지목해 차단하는 것과 정반대다.
> "대량으로 하려거든 우리 프로토콜(API)을 쓰라"고 대안까지 제시한다.
> 이 도구가 API 경로를 택한 것은 그 안내를 그대로 따른 것이다.

### 2-2. 이용약관

- URL: <https://bsky.social/about/support/tos>
- **자동 수집·크롤링·스크래핑·봇·데이터 추출을 금지하는 조항이 없다** (2026-09-06 확인).
- 금지 행위는 별도 문서(Community Guidelines, Copyright Policy, Privacy Policy)로 위임돼 있다.

> ⚠️ **확인하지 못한 것**: Community Guidelines에 자동화 관련 제한이 있는지는 확인하지 않았다
> → [부록](#부록-확인하지-못한-것).

### 2-3. 판정

| 층위 | 판정 | 근거 |
|---|---|---|
| 1. robots.txt | 🟢 **명시적 허용** | `Allow: /` + "may crawl anything" |
| 2. 약관 | 🟢 **금지 조항 없음** | 이용약관에 해당 문언이 없다 |
| 3. 기술적 보호조치 우회 | 🟢 **없음** | 공식 API를 계정으로 인증해 부른다. 로그인 벽을 넘지 않는다 |
| 4. 수집 후 이용 | 🟡 **일반 쟁점만 남는다** | 본문을 영구 적재한다. 저작권법 제35조의5(공정이용) 판단은 다른 소스와 같은 미결 항목이다 |

**실무 결론: 쓴다.** 층위 1·2·3이 모두 깨끗한 유일한 소스다.

### 2-4. 개인정보 처리

| 항목 | 처리 |
|---|---|
| 작성자 핸들 | 🟢 **저장하지 않는다.** 앱 리뷰·다음 카페와 같은 기준 |
| 원문 주소 | 핸들이 URL 경로에 들어간다 — 공개 게시물의 위치이지 별도로 쌓는 축이 아니다 |
| 본문 | 저장한다 (다른 소스와 동일) |

## 3. 비용

**무료다.** 읽기당 과금이 없다.

| 항목 | 값 |
|---|---|
| 검색 호출 | 0원 |
| 계정 | 무료 |
| 앱 비밀번호 | 무료, 개수 제한 없음 |

속도 제한은 포인트 기반(시간당 5,000 포인트 수준)으로 알려져 있고, robots.txt도
"HTTP 429가 백오프 신호"라고 안내한다. 이 도구의 호출량(키워드 9개 × 2쪽)은 그 근처에도 가지 않는다.

> **X와의 대비**: X `api`는 읽기 1건에 $0.005다. 같은 성격(SNS 단문 키워드 검색)인데
> 한쪽은 종량제이고 한쪽은 무료다. [api-costs.md](../api-costs.md) 참고.

## 4. 연동 방법

### 4-1. 사람이 해야 하는 것

| 순서 | 할 일 |
|---|---|
| ① | <https://bsky.app> 가입 (이메일만, 승인 없음) |
| ② | 설정 → Privacy and Security → **App Passwords** → 새로 생성 |
| ③ | `.env`의 `BLUESKY_IDENTIFIER`(핸들 전체)와 `BLUESKY_APP_PASSWORD`를 채운다 |

> ⚠️ **'다이렉트 메시지 접근 허용'을 체크하지 않는다.** 이 도구는 공개 게시물만 읽는다.
> DM 권한을 켜면 그 비밀번호가 새어 나갔을 때 사적인 대화까지 열린다.

> ⚠️ **계정 본 비밀번호가 아니라 앱 비밀번호여야 한다.** 본 비밀번호로는 401이 난다.
> 수집기가 그 경우에 힌트를 붙여 경고한다.

### 4-2. 인증

```
POST https://bsky.social/xrpc/com.atproto.server.createSession
{ "identifier": "<핸들>", "password": "<앱 비밀번호>" }
→ { "accessJwt": "...", "did": "...", "handle": "..." }
```

`accessJwt`는 두 시간쯤 산다. 수집기는 모듈 수준에서 90분간 캐시한다 —
키워드마다 세션을 새로 받으면 로그인 시도가 키워드 수만큼 쌓여 계정이 잠길 수 있다.

### 4-3. 검색

```
GET https://bsky.social/xrpc/app.bsky.feed.searchPosts
    ?q=<키워드>&limit=100&sort=latest&cursor=<이전 응답의 cursor>
Authorization: Bearer <accessJwt>
```

> 🔴 **인증 없이는 403이다.** `public.api.bsky.app`의 다른 엔드포인트(`getProfile`,
> `searchActors`)는 인증 없이 200이 오지만 `searchPosts`만 막혀 있다. 2026-09-06 실측.

### 4-4. 응답 → RawItem 매핑

| RawItem | 응답 필드 | 비고 |
|---|---|---|
| `sourceId` | `posts[].uri` | `at://did:plc:.../app.bsky.feed.post/{rkey}` — 전역 고유 |
| `url` | 조립 | `https://bsky.app/profile/{author.handle}/post/{rkey}` |
| `content` | `posts[].record.text` | |
| `postedAt` | `posts[].record.createdAt` | ISO, 시각까지 온다 |
| `author` | — | 🟢 **담지 않는다** (2-4 참고) |
| `keyword` | 검색어 | 어느 키워드에 걸렸는지 추적용 |

### 4-5. 멈추는 기준

X와 달리 읽기가 무료라 쪽을 넘긴다. 대신 둘로 멈춘다.

| 기준 | 설정 | 동작 |
|---|---|---|
| 쪽수 상한 | `blueskyPages` (기본 2쪽 = 200건/키워드) | 대시보드 수집량 카드에서 조절 |
| **경계 날짜** | `daily.ts`가 DB 최신 작성일에서 뽑아 넣는다 | `sort=latest`라 내림차순 — 경계보다 오래된 글이 나오면 그 키워드는 거기서 끝 |

경계가 없으면(첫 수집) 쪽수 상한까지 내려간다. 실제로 첫 회차에 2023-07부터 들어왔다.

### 4-6. 함정

| # | 함정 | 처방 |
|---|---|---|
| 1 | **따옴표로 구문 검색하면 결과가 크게 준다** | 묶지 않는다. X와 달리 읽기가 무료라 좁힐 이유가 없고, 관련성은 뒤의 LLM 분류가 판단한다 |
| 2 | **같은 글이 여러 키워드에 걸린다** | 회차 안에서 `uri`로 걸러 분류 호출을 아낀다 (저장 단계에서도 걸러지지만 그때는 이미 LLM을 부른 뒤다) |
| 3 | **봇·홍보 계정이 같은 문구를 반복한다** | `dropFlooding`으로 저장 전에 접는다 |
| 4 | 세션 만료(401) | 캐시를 비우고 이번 회차는 접는다. 바로 재발급하면 실패가 반복될 때 로그인 시도만 쌓인다 |

## 5. 붙인 뒤 확인할 것

| # | 확인 | 방법 |
|---|---|---|
| 1 | 인증이 되는가 | 로그에 `미설정, 스킵`이 뜨면 `.env` 두 줄을 확인 |
| 2 | 401이 뜨는가 | 앱 비밀번호가 아니라 계정 본 비밀번호를 넣었을 가능성이 가장 크다 |
| 3 | 언어가 섞여 들어오는가 | 해외 반응이 이 소스의 값이다. 한국어만 들어온다면 키워드에 로마자 표기가 부족한 것이다 |
| 4 | 첫 회차 이후 건수가 줄어드는가 | 정상이다. 경계 날짜가 잡혀 새 글만 담긴다 |
